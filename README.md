# التحدي الرياضي (Altahaddi Sport)

تطبيق تمارين وتحديات رياضية بالعربية، مبني بـ **Flutter** (نسخة محوَّلة من نسخة HTML إلى مشروع أندرويد بنفس أسلوب مشروع «الكوابيس»).

- **الحزمة:** `com.altahaddi.sport`  •  **التطبيق:** التحدي الرياضي  •  **الإصدار:** 1.0.0+1
- **البناء:** عبر GitHub Actions (`.github/workflows/main.yml`) وينتج `app-release.apk`.

## المزايا
1. **4 تمارين:** الضغط، البلانك (مؤقت)، القرفصاء، البطن. زر ابدأ ثم زر تكرار، مع إيقاف مؤقت ومتابعة.
2. **تحديات:** تحدي اليوم (50 ضغطة خلال 5 دقائق بعدّاد تنازلي)، 10 ضغطات، 30 ضغطة، تحدي البطن.
3. **إنجازاتي:** إجمالي التكرارات، أيام التدريب، الدقائق، سلسلة الأيام (يُسمح بيوم راحة واحد).
4. **المستويات والشارات:** مبتدئ ← متقدم ← أسطورة، و4 شارات تُفتح بعدد التكرارات.
5. **حفظ محلي** بـ `shared_preferences`، ويُحفظ ما أنجزته حتى لو خرجت قبل إكمال الهدف.

## تصحيحات عن نسخة HTML
- التحديات لم تعد تعدّل هدف التمرين الأصلي (كل تحدٍّ يحمل هدفه).
- تحدي اليوم يطابق وصفه فعلاً: 50 تكراراً وحدّ 5 دقائق.
- تمرين البطن ظاهر في القائمة السريعة.
- لا يتكرر حفظ الجلسة، وحساب السلسلة يقارن التواريخ بدقة.
- البلانك يعرض الثواني ويمكن إيقافه مؤقتاً.
